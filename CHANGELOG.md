# Changelog

## 1.0.0 — 2026-11-16

Initial public release.

- Short, evidence-based `plan.md` and always-created `tasks.md`.
- External timestamped planning packages with collision-safe project paths.
- Explicit implementation approval and the autonomous execution contract.
- Bounded investigations, meaningful retries and stalled-worker takeover guidance.
- Focused, risk-based verification without redundant test loops.
- Compact templates, three evaluation scenarios and standard-library validation.

Validation covers document structure and policy presence, not measured agent speed
or model obedience. No runtime enforcement or application deployment is included.
